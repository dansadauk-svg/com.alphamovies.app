# Alpha Movies Android v1.0.8

## Clean movie titles in download notifications

- The notification displays only the movie title.
- Example: `1049-1793557352-jnaibpjs-KUNNA-WUTA_6925.mp4` is displayed as `KUNNA WUTA`.
- R2 storage numbers, random keys, trailing IDs and file extensions are hidden.
- Download progress, sound, vibration, Pause, Resume and Cancel remain enabled.
- Includes the Android SDK setup correction from v1.0.7.
